# Host operating-system icons

These images identify the operating system of a saved host. They are not Termvia branding and do not imply endorsement.

- Linux Tux: original SVG from the Linux kernel source tree. Copyright Larry Ewing, created using The GIMP; re-illustrated by Garrett LeSage and refined by IFo Hancroft; see COPYING-Tux.txt. https://www.kernel.org/faq.html
- OpenWrt: original blue/dark-blue icon from the OpenWrt branding repository. https://openwrt.org · https://github.com/openwrt/branding
- Windows: Windows 11 original mark distributed by Devicon; see LICENSE-Devicon.txt. https://github.com/devicons/devicon
- Remaining distro/Apple marks: original brand contours distributed by Simple Icons (CC0); brand color applied without changing paths. See LICENSE-CC0.txt and sources.json for the upstream asset, brand source, guidelines and hashes. https://github.com/simple-icons/simple-icons

Brand names and logos remain the property of their respective owners. Specific upstream notices and guidelines in sources.json apply in addition to the icon collection's license.

Alpine and Debian SVG formatting was normalized without changing their contours.

Small/ contains optical variants for CentOS, Kali, Debian and Raspberry Pi OS, with strokes added for legibility. Modified Debian icons retain CC-BY-SA-3.0. Monochrome marks adapt to the application appearance.

Dark/openwrt.svg is the original OpenWrt white/blue mark from the same pinned branding repository, used on dark surfaces and selected rows.
