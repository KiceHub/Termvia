# Termvia

原生 macOS 终端与 SSH 客户端，集成 SFTP/SCP 文件传输和主机监控。

**1.0.0** · Apple Silicon · macOS 27 及以上

[English](README.md)

## 安装

从 [Releases](https://github.com/KiceHub/Termvia/releases/latest) 下载 ZIP，解压后将 **Termvia.app** 移至「应用程序」。应用使用临时签名，尚未经过 Apple 公证。

## 使用

- 在起始页新建主机，填写 IPv4、IPv6 地址或域名及登录信息，首次连接时核对服务器指纹。本机解析域名时优先尝试 IPv6，经跳板机或 SOCKS5/HTTP CONNECT 代理连接时由上游解析目标域名。支持密码、OpenSSH 私钥和 PuTTY PPK 密钥。
- 起始页也可打开本地终端。会话标签位于顶栏，主机与监控位于左侧。
- 按 **⌘F** 或右键会话标签选择「查找...」，可搜索该标签有焦点的终端窗格和保留的滚动历史。点击放大镜可设置大小写、全字符匹配、循环查找和正则表达式。新打开的文件使用主机当前的查找选项，每个打开的文档可单独调整这些选项，也可替换当前项或全部匹配项。
- 在可搜索的代理设置页管理 SOCKS5、HTTP CONNECT 和 WireGuard。WireGuard 使用应用内共享的用户态网络栈，不改系统路由或 DNS；每台主机可选择上游跳板或代理，跳板支持逐级串联，各级独立认证并核对公钥。
- 右键会话标签或 Shift + 右键终端可上下、左右拆分，连接其他主机或关闭终端；拖动原生分隔线调整大小。文件与监控跟随焦点主机。
- 内置标签编辑器支持 16 MB 以内的文本，可设置语法高亮、行号、缩放、编码和换行。也可在设置中选择外置应用。若文件在内置编辑器外发生了改动，可以先「另存为」保留草稿，再重新打开文件。SSH 断开后的草稿也可以另存到本机。
- 远程编辑器通过原子操作替换文件，并将旧文件保留为同级私有目录 `.termvia-editor-*` 中的 `previous`。每个目录最多保留 64 份，确认无需恢复后可在服务器上清理。服务器无法安全替换的文件以只读方式打开，支持「另存为」。
- 从 Finder 或其他窗口拖入远程文件区可上传；远程项目拖入终端可插入经过 shell 转义的绝对路径。向其他应用拖出下载暂不支持，可使用下载操作或本地文件区。
- 拖动主机或分组调整顺序，默认分组固定置顶。
- 底栏可浏览文件、通过 SFTP/SCP 上传下载，以及查看传输与日志。覆盖上传在整个文件传送完成后才替换原件，需要 SSH 命令权限以保留原文件的元数据。关闭底栏后传输继续，点击右下角按钮可重新打开。
- 设置中可调整终端、监控、登录信息和快捷键，SSH 保活默认关闭。通过 **…** 切换语言和外观。

**⌘T** 新建起始标签，**⇧⌘T** 打开本地终端，**⌘,** 打开设置，长按 **⌘Q** 退出。

## 数据

应用数据位于 `~/Library/Application Support/Termvia/`。首次运行时可选择是否将 SSH 和代理密码、私钥口令及 WireGuard 密钥保存到 macOS 钥匙串，也可在「设置 → 登录信息」中更改。关闭钥匙串后，凭据会存入仅当前账户可访问的本地未加密文件。更新应用后，macOS 可能再次询问是否允许访问钥匙串。

应用使用独立的主机指纹库，不读取 `~/.ssh/config`。传输中断后重传会从头开始。
